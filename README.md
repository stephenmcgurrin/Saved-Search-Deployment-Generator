# NetSuite Script Formatter 🧾

A **Streamlit** web app that helps format NetSuite Saved Search scripts. Paste a raw `search.create` snippet, add metadata, and download a properly structured `require(['N/search'], ...)` deployment script.

Designed for consultants, developers, and NetSuite admins who deploy saved searches via SuiteScript. Based on the work by Chidi Okwudire on his [NetSuite Insights Blog](https://netsuite.smash-ict.com/saved-search-deployment-failed-try-this-before-resorting-to-manual-deployment/).

## ✨ Features

- 📝 Paste your NetSuite Saved Search creation code
- 🔤 Add a custom search name, ID, and description
- 🔄 Automatically generates a formatted `require(['N/search'], ...)` script
- 💾 Download the result as a JavaScript file
- 👀 Preview the formatted script before downloading
- 🧹 Clear the form easily for multiple use cases

## 🚀 Getting Started

### Requirements

- Python 3.9+
- [uv](https://docs.astral.sh/uv/) (recommended) or pip

### Run

```bash
git clone https://github.com/stephenmcgurrin/Saved-Search-Deployment-Generator.git
cd Saved-Search-Deployment-Generator
uv run streamlit run streamlit_app.py
```

Or with pip:

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

Then open the URL shown in the terminal (usually `http://localhost:8501`).

## 🧑‍💻 Usage

1. Paste your `search.create` script (as generated by NetSuite).
2. Enter:
   - **Search Name** – a human-readable name
   - **Search ID Suffix** – the part after `customsearch` (e.g. `_sales_order`)
   - **Description** – brief notes about the saved search
3. Click **Preview** to see the formatted script.
4. Click **Download .js File** to save the result.
